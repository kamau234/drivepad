# Installation

## Mobile PWA

Serve the built `dist` directory over HTTPS (or localhost for development), open it in a supported mobile browser, and use the browser's **Install/Add to Home Screen** action. Service-worker installation requires a secure context.

The current shell is offline-cacheable. Wi-Fi pairing and the Windows bridge will be added in subsequent milestones; the connection indicator is not a fabricated controller connection.

## Windows bridge

The bridge installer is not yet included. It will be published only after a real virtual-controller provider, pairing security, watchdog, and controller test path are verified on Windows.
