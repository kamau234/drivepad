# User Guide

1. Open DRIVEPAD in a supported browser and install it to the home screen.
2. Rotate the phone to landscape.
3. Use the left surface to steer; use the right surfaces for throttle and brake.
4. Nitrous, handbrake, gear, camera, and pause controls are visible in the center on larger screens.
5. The cockpit accepts simultaneous pointer inputs.

Connection is not yet available in this milestone. Do not use the prototype as a Windows controller until the bridge release is documented here.
